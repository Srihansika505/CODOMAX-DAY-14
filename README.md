# Codomax Day 14 – Final Portfolio Website

## 📌 Project Overview

This is my final project for the Codomax Web Development Internship.

The project is a responsive personal portfolio website developed using HTML, CSS and JavaScript.

## 🎯 Objective

To create, test, document and deploy a professional responsive website and submit the complete project through GitHub.

## ✨ Features

- Responsive navigation
- Mobile hamburger menu
- Dark and light mode
- Dynamic greeting
- Smooth scrolling
- Scroll-to-top button
- Project filtering
- Contact form validation
- Social media links
- CSS animations
- Hover effects
- Responsive design
- GitHub Pages deployment

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
